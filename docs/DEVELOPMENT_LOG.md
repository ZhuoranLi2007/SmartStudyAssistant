# 智学规划助手开发日志

> 整理说明：以下日志依据 GitHub `main` 分支提交时间、PR 内容和当前代码演进顺序整理。项目从 2026-07-19 开始，按连续自然日记录至 2026-07-26；其中 7 月 25 日为本地联调与答辩准备，相关代码在 7 月 26 日统一提交。

## 2026-07-19：项目初始化与全栈 MVP

### 当日目标

搭建可运行的 HarmonyOS NEXT 教育应用骨架，完成客户端与后端的第一条业务链路。

### 完成内容

- 建立 HarmonyOS NEXT API 24 工程，使用 ArkTS、ArkUI 和统一 `Navigation + NavPathStack + PageMap`。
- 完成登录、注册、首页、学生档案、课程、试卷、学习计划、AI 助手和个人中心基础页面。
- 创建 FastAPI 后端，划分 API、Service、Model 和数据库访问层。
- 实现 JWT 登录、学生档案、课程、试卷、学习任务和基础推荐规则。
- 将开发数据库切换到 MySQL，建立初始化脚本、Alembic 迁移和 `.env.example`。
- 保留 SQLite 作为自动化测试数据库，避免测试影响开发数据。

### 遇到的问题与处理

- 设备不能通过电脑的 `127.0.0.1` 访问后端，改为局域网 IPv4，并让 Uvicorn 监听 `0.0.0.0`。
- SQLAlchemy 与 asyncmy 的空闲连接检测存在兼容问题，使用连接回收降低失效连接复用概率。
- 将密码、JWT Secret 和模型 Key 全部移到环境变量，避免进入 Git。

### 当日结果

- 客户端、后端和 MySQL 可以完成基础注册登录与数据访问。
- GitHub 依据：`c064cc7`、`19e6c3d`、`2641cff`。

## 2026-07-20：AI 全链路与界面完善

### 当日目标

把原有 Mock 问答升级为可解释、可追踪的 AI Agent 学习顾问，并完善首页和个人中心。

### 完成内容

- 接入 DeepSeek 与 Mock Provider，形成统一普通响应、JSON 响应和 SSE 接口。
- 实现 13 类意图、实体提取、缺字段追问、8 个白名单业务工具、RAG 和多轮会话记忆。
- 增加课程、试卷、学习计划、订单等结构化卡片和来源展示。
- 使用 `clientMessageId` 保证 SSE 降级重试的请求幂等。
- 重构首页、在线练习和个人中心，补齐我的课程、收藏、错题、报告、客服和设置等页面。
- 增加 AI 全栈数据库实体、增量迁移、工具日志和推荐记录。
- 更新 README、接口、AI 架构、提示词、测试和答辩材料。

### 遇到的问题与处理

- 学生档案 ID 失效会导致首页和 AI 请求重复 404，改为登录恢复后重新获取当前档案。
- cards、sources 和流式状态放在页面全局会串到历史消息，改为绑定到具体消息对象。
- SSE 首段失败可能重复执行业务，普通接口降级必须复用相同消息 ID。

### 当日验证

- 当时完整后端测试为 `17 passed`。
- HarmonyOS API 24 HAP 构建成功。
- GitHub 依据：PR [#1](https://github.com/ZhuoranLi2007/SmartStudyAssistant/pull/1)、PR [#2](https://github.com/ZhuoranLi2007/SmartStudyAssistant/pull/2)。

## 2026-07-21：个性化学习闭环与课程体验

### 当日目标

让学生档案真正影响课程、试卷、计划、错题和练习流程，并提升课程详情体验。

### 完成内容

- 重构学生档案编辑，完善年级、学科、成绩、薄弱点、目标和学习时长字段。
- 将学习计划页拆分为周日期、任务摘要、任务卡片、推荐试卷和推荐错题组件。
- 增加错题原题复测页面，正确后更新掌握状态和对应学习任务。
- 完善课程与试卷推荐条件，使成绩分层和薄弱知识点参与真实匹配。
- 增加课程本地视频、封面、教师信息、课程大纲、评价和底部操作栏。
- 收藏功能接入后端持久化，并保留网络异常时的演示降级。
- 修复 AI 回复朗读切换、任务状态和页面真实连通问题。

### 遇到的问题与处理

### 当日结果

## 2026-07-22：真实题库与错题功能

### 当日目标

补齐试卷题目数据，解决选项重复、错题信息不完整和目录不一致问题。

### 完成内容

- 建立 `paper_questions.json`，为目标试卷注入真实题目、选项、正确答案、解析和知识点。
- 通过题库内容哈希和逐题校验控制幂等重建。
- 修复题目选项重复和题号不稳定问题。
- 在错题本中增加错误次数、原答案、正确答案和解析。
- 提交练习后自动沉淀错题，并同步最近一条对应学习任务状态。
- 公共试卷目录更新时保留用户生成试卷，避免种子逻辑误删个性化数据。

### 遇到的问题与处理

- 只靠 `create_all()` 无法修复已有表字段，增加兼容补丁并保留 Alembic 作为正式迁移依据。
- 每次启动重建全部题目会破坏稳定 ID，改为哈希变化或逐题不一致时才重建。
- 错题必须绑定真实题目外键，旧客户端缺少题目 ID 时增加兼容处理。

### 当日结果

- 试卷详情、在线答题、评分、解析和错题本使用真实题目数据。
- GitHub 依据：PR [#4](https://github.com/ZhuoranLi2007/SmartStudyAssistant/pull/4)。

## 2026-07-23：语音识别与 AI 组卷

### 当日目标

增加语音输入和 AI 数学组卷，完善 AI 助手的多模态交互入口。

### 完成内容

- 增加 HarmonyOS `AudioCapturer` 录音、WAV 封装和麦克风权限申请。
- 前端优先调用后端长语音识别，失败时回退设备原生 ASR。
- 后端接入 Vosk、Google 和 Sphinx 识别路径，以及 ffmpeg/pydub 音频转换。
- 增加 AI 组卷页面、我的试卷页面和相关 API。
- 使用结构化 JSON Prompt 生成 5 道小学数学选择题，并验证选项和正确答案格式。
- 支持根据未掌握错题生成相似但不重复的复习试卷。
- 修复 AI 组卷命名、收藏关联和删除后的序号整理问题。

### 遇到的问题与处理

- 模拟器不一定支持 CoreSpeechKit，必须保留能力检测和后端识别降级。
- 音频格式不统一会导致识别失败，统一转换为 WAV 后再预处理和切片。
- 模型可能返回 Markdown 代码块或非法 JSON，增加安全解析、字段验证和演示试卷兜底。

### 当日结果

- 用户可以通过语音输入咨询，并生成、查看和删除自己的 AI 数学试卷。
- GitHub 依据：PR [#5](https://github.com/ZhuoranLi2007/SmartStudyAssistant/pull/5)、[#6](https://github.com/ZhuoranLi2007/SmartStudyAssistant/pull/6)、[#7](https://github.com/ZhuoranLi2007/SmartStudyAssistant/pull/7)。

### 当日目标

### 完成内容
